# Reconciliation Rules

## Portfolio denominator
State whether weights are % of identified Indian equity book, % of total scheme AUM, or % of benchmark. Show residuals for cash, debt, foreign, unlisted, derivatives and unmapped assets where relevant.

## Contribution
Stock contribution -> industry/theme -> sector -> total. Bottom-up totals must reconcile within explicit tolerance.

## Attribution
Do not force holdings-based contribution to equal NAV active return when timing, cash, corporate actions or data conventions differ. Show explained return plus residual if necessary.

## Portfolio bridge
Opening value + quantity effect + price effect + corporate-action/residual = closing value.

Do not call value appreciation 'buying' unless share/quantity evidence supports it.

## Terminology
Use precise labels such as 'Combined weight of top 5 equity holdings (%)' rather than 'Top-5 %'.

## Quality gate
Verify scheme, plan, option, benchmark, dates, peer universe, total weights, contribution roll-up, active-weight roll-up, quantity-price bridge, units, sources and residuals.
