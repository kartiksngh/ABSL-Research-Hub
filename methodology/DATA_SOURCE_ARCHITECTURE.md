# Data Source Architecture

## Performance truth — MF Peerset Comparison
Use as preferred source for trailing returns, calendar-year returns, rolling returns, category average/median, peer rank, quartile, volatility, Sharpe/Sortino/information ratio, beta/tracking error, drawdown, capture and consistency metrics where available.

Reconcile scheme identity, Direct/Regular, Growth/IDCW, benchmark, inception date, observation date and TRI/PRI before combining.

## Portfolio truth — Vistas Terminal
Primary sources include Fund Skill, AMC Book, Ownership & Flow, Asset Allocator, revisions, benchmarks, market regime, liquidity and crowding.

Use AMC Book for monthly holdings and portfolio changes. Do not infer buying from market-value or weight increases; use quantity/share evidence.

## Cross-verification
Use ABSLAMC disclosures, AMFI, SEBI, NSE/BSE, RBI/NSDL/MOSPI where relevant, and company filings/investor presentations to validate material facts.

## Source labels
Every exhibit must show source, as-of date, unit and denominator. For mixed exhibits, label which source contributes which field.
